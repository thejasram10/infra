# Stage 1 – Terraform Repository Setup

**Project:** ZenPharma DevSecOps\
**AWS Region:** `us-east-1`\
**GitHub Username:** `thejasram10`

## 1. Create the folder structure

Open PowerShell:

```
cd D:\DevSecOps-Project-by-Rushi\devops\zenpharma\infra
```

Create directories:

```
New-Item -ItemType Directory -Force -Path envs/dev, envs/qa, envs/prod, modules/vpc
```

Create placeholder files:

```
New-Item -ItemType File -Force -Path envs/dev/.gitkeep, envs/qa/.gitkeep, envs/prod/.gitkeep, modules/vpc/.gitkeep
```

## 2. Initialize Git

```
git init -b main
git rev-parse --show-toplevel
```

Verify that the repository path ends with `infra`.

## 3. Create .gitignore

Create `.gitignore` in the infra folder:

```
**/.terraform/
*.tfstate
*.tfstate.*
*.tfplan
*.tfvars
*.tfvars.json
.env
.env.*

.idea/

```

## 4. Create the first commit

```
git add .
git status
git commit -m "chore: initialize Terraform infrastructure"
```

Verify:

```
git log -1 --oneline
```

## 5. Create a GitHub repository

1. Open [https://github.com](https://github.com)
2. Sign in to your GitHub account.
3. Click **New Repository**.
4. Repository name: `infra`
5. Select **Private** or **Public**.
6. Do not initialize with README, .gitignore or License if you already created them locally.
7. Click **Create Repository**.

Repository URL:

`https://github.com/thejasram10/infra`

## 6. Connect local repository to GitHub

Check existing remote:

```
git remote -v
```

If no remote exists, add it:

```
git remote add origin https://github.com/thejasram10/infra.git
```

If the remote already exists, update it instead:

```
git remote set-url origin https://github.com/thejasram10/infra.git
```

Verify:

```
git remote -v
```

## 7. Push code to GitHub

Check the branch:

```
git branch --show-current
```

Ensure it is `main`:

```
git branch -M main
```

Push:

```
git push -u origin main
```

Refresh your GitHub repository page and verify that your files are visible.

If GitHub already contains commits, synchronize the histories safely before pushing. Do not use `git push --force`.

## 8. Future Git workflow

Whenever you make changes:

```
git status
git add .
git commit -m "your commit message"
git push origin main
```
